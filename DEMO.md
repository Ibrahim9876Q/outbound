# Outbound · Three-minute judged demo

Rehearse from the integrated Windows checkout. Before the timer, press **Scan this PC** and wait for the permission history and scan summary. Leave that completed scan in the same running server. Put Computer on screen and confirm Rules shows the local provider and dry-run enforcer. Review any local records before projecting them. Start with real traffic already present or use the local fallback below.

## Fallback appendix

- If the scan is still running, show completed sections as they become available, or use a reviewed recording of an actual run. A new scan replaces the previous result. The local app-data walk can continue after the browser and permission results are ready.
- If venue Wi-Fi stalls, use the observed destinations still retained within the time and per-app caps. With the QA server on 4319, `curl.exe -N http://127.0.0.1:4319/events -o NUL` creates a real local connection that appears in Computer or Links. Stop that curl with Ctrl+C. If the run has few geographic estimates, state the count shown and use the country detail list when available.
- If asked about device indicators, use a preapproved camera preview. The webcam lamp is white. The orange microphone key and the white lamp indicate Windows sessions, and durations reflect the observations.
